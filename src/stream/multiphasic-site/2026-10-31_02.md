## Why Care?

The context-vigilance kit has a baseline frontmatter template: `title`,
`date_created`, `date_modified`, `site_uuid`, `hex_code`, `authors`, and it
writes `authors` and `augmented_with` as lists. Every doc that follows it can
be sorted, linked, and rolled up the same way as every other doc in the tree.

This pass changes only shape, never meaning. No value changes, and no date is
set to the day of the sweep.

## What's New?

- **`augmented_with`** in
  `context-v/specs/Multiphasic-Site-Messaging-and-Creative-Brief.md` is now a
  one-item list, not a bare string. The model string is exactly as it was.

The spec already had its `title`, dates, `site_uuid`, `hex_code`, and
`authors`, so nothing was added.

Part of the tree-wide sweep planned in the context-vigilance kit:
`ai-labs/context-vigilance-kit/context-v/plans/Retrofit-Every-Repo-to-OKF-Then-the-Kit-Frontmatter.md`.
