## Why Care?

`context-v/` holds the plan for Stenographer's next big change, a local transcription engine. It is now an Open Knowledge Format (OKF) v0.2 bundle, so any OKF reader can list what's here without opening each file.

## What's New?

- **The local-engine spec declares `type: Specs`**, the name of its folder. It stays `Draft`: the engine isn't built yet.
- **`context-v/index.md`** marks the bundle with `okf_version: "0.2"`, and `specs/index.md` lists the spec with its lede.
- **The `Stenographer` tag comes off the spec.** It named the repo the spec lives in, which the body already does; the topic tags stay.
