## Why Care?

`date_created`, `date_modified`, `site_uuid`, `hex_code`, `authors`. Every
doc that carries all of them can be sorted, linked, and rolled up the same
way as every other doc in the tree.

This pass fills only what's missing, and only from facts. Nothing is
guessed, no existing value changes, and no date is set to the day of the
sweep.
