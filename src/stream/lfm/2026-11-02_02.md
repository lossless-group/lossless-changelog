## Why Care?

Finding out what LFM can do meant reading through hundreds of lines of wikilink design. Mermaid support barely appeared at all. The README now answers what LFM is, how to install it, and what you can write, then links to a guide for each feature.

## What Changed

- **The README** now has one table of what you can write, what setup each feature needs, and where its guide is.
- **`docs-v/` is the new docs folder.** The name means docs, and the README and `AGENTS.md` both say so.
- **Mermaid** has its own table row and a guide section. LFM recognizes the block, and your site draws it with mermaid.js.
- **`CONTRIBUTING.md`** now holds the test notes and plugin naming rules.

## Fixes Made Along the Way

- The install example pointed at `^0.3.0` and now points at `^0.7.0`.
- The test count was out of date, so the number is gone.
- The roadmap no longer lists wikilinks and the heading outline as future work.
- A dead link to `../lfm-astro/` is gone, and two old plugin names are corrected.
