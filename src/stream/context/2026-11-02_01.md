## Why Care?

The skills called four-part versions the one right answer, while semver is the
market standard and package tools reject four parts. Agents also need to read
each format correctly: the `1` in `0.1.0` is a minor, and the `1` in `0.1.0.0`
is a major. Separately, Markdown in ledes was showing up as literal symbols on
cards and previews.

## What's New?

- **Three version formats:** `major.minor.patch`, `epoch.major.minor.patch`, and
  [Epoch SemVer](https://antfu.me/posts/epoch-semver), which writes epoch 1,
  major 2 as `1002.3.0`. The user picks, and nothing is enforced.
- **No migration:** agents keep the format already in use and never convert a
  version. Templates still start at `0.0.0.1`.
- **Plain-text ledes:** `context-vigilance` and `changelog-conventions` now say a
  lede is a string, with no backticks, asterisks, links, or wikilinks.
