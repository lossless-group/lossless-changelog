## Why Care?

HubSpot ships its own remote MCP server and a native Claude connector, so an agent can reach a client's CRM in a few clicks. What it doesn't ship is judgment. Most writes ask for confirmation, but the prompt looks the same for editing one contact as for adding a property every user in the account will see. This skill draws that line, and the others an agent needs to work a client's HubSpot without making a mess.

## What's New?

- **`hubspot-interface/`**, marked draft.
- Three grounding calls every session: `get_user_details`, `discover_hubspot_schema`, `tool_guidance`.
- Four safety tiers: read, record write, account-wide schema, public or outbound.
- The data-model rules that bite: internal names vs labels, stage IDs, associations, activities as linked objects.
- Dedupe rules: contacts dedupe on email, companies don't dedupe on domain over the API, and there's no merge over MCP.
- Recurring jobs: answer a question, log a conversation, move a deal, intake a batch, report with coverage first.
- `references/tool-map.md`, with all 32 public tools tiered, and `references/connector-setup.md`, comparing the native connector, a custom MCP connector, and an operator private app.
- Uses the public skill / private config pattern. Portal facts live in a gitignored `config/private.json`.
