## Why Care?

Markdown has two meanings for `---`. On a file's first line it opens YAML frontmatter. Directly under a paragraph it is a *setext heading underline*, so the paragraph above becomes an H2. A pipeline that writes `---` as a section break straight after a paragraph will, sooner or later, ship a document where a full paragraph renders as a giant heading. We shipped exactly that in an exported investment memo.

## What's New?

- **Rule 6 in `lossless-flavored-markdown`:** section breaks are `***`, with a blank line above and below, in every markdown file in the tree. `---` is reserved for the opening frontmatter.
- **Code that writes** markdown emits `***`. **Code that reads** breaks accepts both, so older files still parse. Table delimiter rows (`|---|`) are unaffected.
- **A new common-pitfalls bullet** names the failure mode, so it's easy to spot in review.

## Where it's enforced

The memopop orchestrator enforces it in code. A small `md_breaks` module sets the break string, matches either spelling, and normalizes LLM output before anything is written or exported.
