## Why Care?

Most of our sites and every splash page should tell us whether anyone is visiting. OpenPanel does that, and it's already in ten sites. But the knowledge of how to set it up lived in a rollout prompt, so each new site meant rediscovering the same traps. The worst one is a missing "supported domain": every event gets rejected while the script looks healthy, and we once lost a night to it.

## What's New?

- **`openpanel-analytics` skill:**
  - the component to copy
  - where `OPENPANEL_CLIENT_ID` goes on GitHub Pages, on Vercel, and on both
  - the supported-domains rule
  - a checklist that proves events arrive (curl for the script, then a 200 from `api.openpanel.dev/track` in a clean incognito window)
- **README** lists it next to Maintain Splash Pages, which every splash pairs it with.

## Known Gotchas

- The rollout history and per-site status stay in `context-v/prompts/Setup-Analytics-Across-Sites.md` at the anchor root; the skill points there instead of copying it.
