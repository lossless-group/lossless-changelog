## Why Care?

`lossless-agent-skills` is a public reference collection — other Lossless repos
link here, external agents pull skills from here, and the README rendered on
GitHub is fine but flat. A splash gives the collection an indexed catalog
surface with search, a sortable list, per-skill detail pages, and a changelog
view that an external reader can actually navigate.

It's also the first instance of a splash where the **content shape diverges
from the canonical changelog + context-v pair** — this repo *is* a context-v
in the parent monorepo, so the natural primary collection is the skills
themselves. The splash auto-discovers `<repo>/*/SKILL.md` (and one level
deeper for the chroma submodule).

## What's New?

A fresh `splash/` directory at the repo root, deployed to GitHub Pages on push
to `main`:

- **Operator/CLI posture** — dark by default, JetBrains Mono display +
  Inter body, blueprint-grid background, brutalist hairline cards. Deliberately
  distinct from the sibling Lossless splashes (memopop, content-farm, lfm).
- **Skills catalog** as the primary content surface — auto-discovers every
  `*/SKILL.md` and renders each one with title, status, tags, and the body.
- **Changelog** rendered alongside, following the existing convention.
- **Pagefind** for full-text search across every skill body and changelog
  entry. `/` shortcut to focus the header popover; dedicated `/search/` page
  for full-panel search.
- **SortControls** on list pages — modified / created / published / title for
  changelog, title / status for skills.
- **Three-mode toggle** (dark / light / vibrant) with pre-paint mode resolution
  and per-page sort persistence in localStorage.
- **`open-graph-share-seo-geo` discipline applied** — `@astrojs/sitemap` with
  the standard filter, `public/robots.txt` with the absolute Sitemap URL,
  `/llms.txt` + `/llms-full.txt` endpoints with markdown templates as the
  source of truth for voice, JSON-LD (`TechArticle` for skills, `BlogPosting`
  for changelog) injected via `MetaTags.astro`, all six OG image properties
  emitted including `og:image:secure_url`.

Build verified: 22 pages generated, 18 indexed by Pagefind (list/home/search
pages opt out by design — they're not where users want to land from a search
result), sitemap clean (no `llms.txt` / `404` leakage), llms.txt fully
populated with absolute URLs.

## Also included

- New `.github/workflows/pages.yml` for the Pages deploy. Uses
  `actions/deploy-pages@v4` and `actions/configure-pages@v5` with
  `enablement: true` so Pages bootstraps itself on first run. `submodules:
  recursive` so the chroma vendored skills are available to the catalog glob
  at build time.
- `splash/README.md` — local dev, deploy, content sources, divergence table
  vs. sibling splashes.
- OG image is currently a placeholder URL in `src/lib/seo.ts` — needs to be
  replaced with an ImageKit-hosted 1200×630 JPEG before the splash gets
  shared widely (the `generate-consistent-og-images` skill is the right tool
  for that, but waiting until DESIGN.md is authored — out of scope here).
