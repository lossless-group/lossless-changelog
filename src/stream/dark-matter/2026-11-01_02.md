# Changelog - 2026-11-01 (#2)

## Dark Matter's Blueprints Get Statuses That Fit What They Are

### Why Care?

[[2026-11-01_01]] made `context-v/` an Open Knowledge Format bundle. This pass checks its four docs against the Context Vigilance Kit's baseline frontmatter and status vocabulary, so a dashboard grouping docs by status puts each one in the right column.

### What's New?

- **Jumbotron Popdown Patterns is `Active`**, not `Shipped`. It's a pattern to follow when adding a header dropdown; the `JumboDropdown` component family it lays out was never built here (the header's Explore dropdown is inline), so "shipped" overstated it.
- **Using Heartbeat Patterns to Save Session Data is `Reference`**, not `Shipped`. It explains the session-tracking system as built, and that code is still in place (`SessionHeartbeat.astro`, the session-heartbeat API route).
- **The master site spec gains `date_first_published: 2025-12-04`**, the day the theme, mode toggle, and base layout it describes were committed. A `Shipped` doc needs that date.

### Under the Hood

- Part of the tree-wide OKF sweep; see the Context Vigilance Kit's plan, Retrofit-Every-Repo-to-OKF-Then-the-Kit-Frontmatter.
- Every edit was made by hand. No body line changed and no existing date moved.
- Every doc already carried a `site_uuid`, `hex_code`, title, dates, and authors, so no IDs were minted and no keys were filled.
- The Team Page Living Spec stays `Draft`. The team page was later built with differently named `TeamMemberCard` components, so whether this checklist is stale is a call for its author.
