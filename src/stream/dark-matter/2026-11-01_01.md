# Changelog - 2026-11-01 (#1)

## Dark Matter's Context Docs Now Say What They Are

### Why Care?

`context-v/` holds the docs an agent reads before touching this site: the master site spec, the team-page checklist, and the blueprints for the header dropdowns and session heartbeats. It is now an Open Knowledge Format (OKF) v0.2 bundle, so any OKF reader can list what's here and what each doc is for without opening a thing.

### What's New?

- **All 4 docs declare their `type`**, the Train-Case name of their folder: `Blueprints` or `Specs`.
- **`context-v/index.md`** marks the bundle with `okf_version: "0.2"` and lists its two folders.
- **Two folder indexes**, one line per doc with its lede.

### Under the Hood

- Part of the tree-wide OKF sweep; see the Context Vigilance Kit's plan, Retrofit-Every-Repo-to-OKF-Then-the-Kit-Frontmatter.
- Every edit was made by hand. The doc diff is 4 added `type:` lines and nothing removed. No dates moved: this is a compliance change, not a content change.
- The site doesn't load `context-v/` into any page, so no code changed.
