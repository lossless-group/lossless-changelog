## Why Care?

The context-vigilance kit's baseline frontmatter gives every doc the same
identity and date fields, so roll-ups, the survey, and any OKF tool can
sort and cite them without guessing. This is Phase 2 of the tree-wide
retrofit sweep: fill what's missing from facts only, and bring existing
values up to the standard without changing what they say.

## What's New?

- **`date_created`** added to four docs (both explorations, both plans),
  each from its `date_authored_initial_draft`.
- **`date_modified`** added to five docs (the same four, plus
  `citations/definitions.md`), set to 2026-08-18, the date of each file's
  last commit before this sweep.
- **`augmented_with`** is now a one-item list in 21 docs, every value
  unchanged.
- **Tags in Title-Case:** `reach-edu` became `Reach-Edu` in the seven
  pre-RAG stories and the 16:9 export plan, and `pptxgenjs` became
  `Pptxgenjs` in that plan. No tag was added, dropped, or merged.
- **A fix to the previous entry:** `changelog/2026-10-31_01.md` now
  writes `augmented_with` as a string and carries `at_semantic_version`,
  as this site's changelog collection schema requires; without it the
  `/changelog` build would reject the entry.

Facts only: no existing value, body line, status, or version in any
context-v doc changed, and no date is the day of the sweep. Every doc
already carried `title`, `site_uuid`, `hex_code`, and `authors`.
