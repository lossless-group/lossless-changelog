# Eight More Projects, and a Ledger That Folds

## Why Care?

This site is supposed to show everything we shipped, and it had quietly fallen behind. Eight public repos were writing changelog entries that never appeared here, some of them for months. They're in now, so the page tells the whole story again.

The project list also got easier to read. It had grown long enough that every sub-project, always open, buried the top-level picture. Now it opens on the top-level families. Click one to see what's inside, and click a name to go straight to its log.

## What's New?

- **Eight new streams, 42 entries:** [Tidyverse](/stream/tidyverse/), [Lossless Analysis](/stream/lossless-analysis/), [Hope AI](/stream/hope-ai/), [Kay OS](/stream/kay-os/), [Event Hog MCP](/stream/event-hog-mcp/), [Astro Knots MCP](/stream/astro-knots-mcp/), [Mandatory Ventures](/stream/mandatory-ventures-site/) and [DidiDecks Player](/stream/dididecks-player/).
- **A folding ledger.** Every project with sub-projects shows a caret and a count. It starts collapsed and nests to any depth: AI Labs opens to show DidiDecks AI, which opens to show its client sites and player.
- **Lossless Site wears the v3 mark**, picked up from the site's new favicon.

## How We Found Them

The manifest is an explicit allowlist on purpose, so nothing rolled up from a parent repo ever shows up twice. The cost is that a new repo shows up only when someone adds it. So we walked every git repo in the tree, kept the ones with entries in `changelog/`, and compared that list against `streams.yaml`. Twenty-five repos were missing. Some were already excluded on purpose (private, or stats-only). Of the rest, ten turned out to be private, and those stay out: this site is public, and a token that can read a private repo must never be the reason its contents go public. They're now listed in the manifest's "deliberately NOT aggregated" block, so the next audit doesn't rediscover them. That left eight public repos, which are the ones added here.

Every stream also needs a subscription in the hook relay, or a push only shows up after the five-minute cache expires. All eight got one.

## Under the Hood

`ProjectTree.astro` is a recursive component: a project with children renders as a `<details>` whose `<summary>` is the `ProjectRow`, followed by another `ProjectTree` one level deeper. The page used to hand-write three levels of nested lists. The pattern comes from the [Context-V Corpus](https://lossless-group.github.io/context-v-corpus/) splash, where it replaced the same always-open list. `ProjectRow` gained an `expandable` prop for the caret and the sub-project count. Leaf rows keep an invisible caret so titles stay aligned down the column.
